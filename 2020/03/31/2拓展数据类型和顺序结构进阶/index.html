一、标准数据类型

　　之前我们已经学过三种基本且常用的数据类型：int，double和char。本帖再介绍剩下的几个标准数据类型。

　　介绍之前，先想两个问题：

　　１）从\(-2\)到\(2\)，一共有多少个整数？从\(-100\)到\(100\)呢？

　　２）什么是组合数学的乘法原理？

1.1 整数类型

　　我们已经学过int，它是有符号的３２位整数，其完整的全称是[signed] [int]，中括号表示其中的内容可以不写。也就是说，int a;等效于signed a;，也等效于signed int a;。其表示范围是\(-2^{\textcolor[RGB]{255,0,0}{31}}\sim2^{31}-1\)，也就是\(-2,147,483,648\sim2,147,483,647\)，即大约\(\ \textcolor[RGB]{255,150,0}{-21}\)亿　到　\(\textcolor[RGB]{255,150,0}{21}\)亿，或者说约是\(-2.1e\textcolor[RGB]{255,0,0}9\sim2.1e9\)。

　　这个范围是从何判定出来的呢？因为int是用４个字节来表示一个整数，也就是说，一共有３２个bit。而且它是有符号的，也就是说，３２个bit中，左侧最高位是符号位（０表示正，１表示负），剩下的３１个bit表示这个数的绝对值。每个bit有０或者１这两个值可供选择，也就是每个bit有２个选择。我们书写一个有３１个bit的二进制，一共有３１个步骤（每个步骤写１个bit的值），且每个步骤有２个选择，根据组合数学里的乘法原理（如果一件事情前后分为\(n\)个步骤，且每个步骤有\(a_i(i\in[1..n])\)个选择，则整件事情可以有\(a_1*a_2*a_3*...*a_n\)种选择），则这个数字一共有\(\overbrace{ 2*2*2*...*2*2 }^{\text{31个2}}=2^{31}\)这么多个可能性，每个可能性能够表示一个不同的数字。但因为整数在内存中都是以补码的形式存在，一个int的变量的最大值的二进制补码形式是\(0B0\ \overbrace{111...11}^{31个1}\)。这个数并不是\(2^{31}\)，而是\(2^{31}-1\)；同时，一个int的变量的最小值的二进制补码形式是\(0B1\ \overbrace{000...00}^{31个0}\)，这个二进制补码对应的原值是\(-2^{31}\)。

　　我们可以用unsigned [int]这个数据类型（无符号的int）来进一步拓展范围。signed表示有符号的，而unsigned表示无符号的。也就是说，把原来的最高位的那个符号位也用来表示数值。这样的话，就无法表示负数了，但正数的表示范围翻了一倍，所以unsigned int的数据范围是\(0\sim2^{64}-1\)，即从\(0\)到\(42\)亿左右，或者说是\(0\sim4.2e9\)。这个范围其实也不算太大……所以很少会用到unsigned [int]这个数据类型。

　　对于超大规模的数据，一个比较有效的措施是采用一种新的数据范围更大的整数类型，即[signed] long long [int]。

1.1.1 [signed] long long [int]有符号的超长整数★★★

　　一个[signed] long long [int]（中括号表示其中内容可以不写）类型的整数，是用８个字节来表示一个整数，除了最高位的符号位之外，还有６３个 bit可以表示绝对值，其数据范围是\(-2^{\textcolor[RGB]{255,0,0}{63}}\sim2^{63}-1\)，大约是\(-9.22e\textcolor[RGB]{255,0,0}{18}\sim9.22e18\)。如果采用unsigned long long int的话，范围是\(0\sim1.84e19\)，基本上能涵盖所有常规的整数范围（除非题目要考你高精度整数）。“十年OI一场空，不开long long见祖宗”，指的就是在考场上因为没有给某些变量设置成long long类型，从而导致数据溢出而丢分的情况。所以，在内存允许的前提下，强烈建议都用[signed] long long [int]来定义整数变量或整数数组。

　　这种类型的数据，在使用scanf和printf函数进行输入输出时，其对应的通配符是%lld。（注意，是２个l）

1.1.2 int64_t

　　有时候会在其他一些算法平台网站（例如洛谷）上看到有同学写的代码是这个类型。这个类型是在C++11版本当中出现的一个宏定义，其本质仍然是long long或者long，对其进行了统一的规定，使得代码跨平台的兼容性更好，但不允许隐式类型转换了。这个类型有点鸡肋，通配符书写麻烦，基本上被弃用，但要求同学们能看得懂，它实际上就是披着int64_t类型外衣的long long类型的数据。

1.1.3short [int]　短整型★

　　我们已经知道int占４个字节，long long占８个字节，那这个短整型呢？很简单，它占２个字节，最高位是符号位，剩下的１５个bit用来表示整数的绝对值。按照之前的分析方法，可以知道，它的数据范围是\(-2^{15}\sim2^{15}\)，即\(-65536\sim65535\)。这个类型在实战中使用的概率不高，基本被弃用，但也应小心初赛的选择题或者判断题。

　　在scanf和printf函数中的通配符是%hd。

1.1.4 signed char 单字节有符号整数

　　signed char类型的整数，用１个字节来表示整数，最高位是符号位，剩下的７位用来表示整数的绝对值，所以其表示范围是\(-2^7\sim2^7\)，即\(-128\sim127\)（注意，\(2^8=256\)）。因为其表示范围很小，故平常极少采用这个类型来存储整数值，一般情况下我们不缺那点内存，没必要这么节省，万一溢出造成数据错误，就太得不偿失了。需要注意的是，这个类型是可以表示负整数的，所以它更适合存储小的整数值。

　　和它比较容易混淆的还有２个类型，分别是char和unsigned char。char更适合存储字符常量，而unsigned char因为没有符号位，８个bit都用来表示数值，所以更适合在简单的二进制数据计算中表示变量。

1.2 实数类型

　　我们已经学会了double类型，它能解决信息学竞赛中几乎%99的关于实数的问题。不过，同学们还是需要知道另外还有两个实数类型，那就是float类型和long double类型。

　　１）float类型，叫做单精度浮点数。如果是自己写代码，基本上不会用这个类型，因为它能搞定的事情，double类型都能搞定。虽然它的内存空间比double少一半，但也不算特别明显，而且现在MLE（程序所用内存超限）的概率都很低，为了避免数据溢出，通常情况下都用double来表示实数。需要小心一点的就是，double的通配符是%lf，而float的通配符是%f，尽量不要混淆。

　　２）long double类型，叫做长精度浮点数，在C９９版本中拟定，用１６个字节来表示一个实数，其表示范围大约在\(±1.2×10^{-4932} \sim ±1.2×10^{4932}\)（不需要背）之间，其有效的位数达到\(18\sim19\)位（超过这个位数的内容可能不再精准）。这个类型的范围很大，平时基本上用不到这个数据类型，只做了解即可。

1.3 bool（布尔）类型

　　这是一种比较特殊的类型。我们经常需要做一些关系运算或者逻辑运算（在后面的选择结构和循环结构中会正式讲），这些运算的结果值，就是bool类型。这个类型只有２个值（整数类型有无限个值，实数也是，字符型的值根据其bit数来决定，也是有限个的），那就是“真”和“假”，或者说是“正确”和“错误”，对应地用true和false来表示这两个值。注意，这不是两个字符串，或者两个汉字，在编码时不需要加双引号。

三、顺序结构进阶

3.1 顺序结构编程基本套路

　　对于一般的比较简单的顺序结构题，基本上都遵循下面的基本套路：

　　１）定义相关变量（尽量遵循题意，题上说\(x\)是什么类型，就定义成什么类型），若有必要的话可以给其赋予初始值。

　　在给变量取名字的时候，名字尽可能贴近其实际用途（例如“个数”可以用cnt或者c表示；“总和”可以用sum表示并赋初始值为0，“总个数”可以用n表示；无差别的两个数可以用x1和x2表示），尽可能不要用a、b、c、d这种没有意义的名字。

　　如果题目上已经给一些变量取好了名字，个人建议不必理会。很多人在出题的时候，对变量的取名都非常随意，如果直接采用这些名字，会让你在后期阅读自己代码时难以快速读懂。

　　２）根据题意，录入输入数据。

　　数据一定要有具体的值，才能参与计算。不能用乱码去计算，否则得出来的结果一定也是乱码。在录入的时候，可以用cin>> ...或者scanf("%...", &..);的方式来录入。注意，在用scanf函数时，字符串里只放通配符，尽量不要再有其他字符（例如scanf("a=%d", &a);或者scanf("%d\n", &a);，这些都是非常容易出错的输入语句）

3.2 常用的数学函数

　　下面的这几个数学函数，都需要#include <cmath>。当然，万能头文件里面已经包含好了。但建议还是留意一下这个头文件名字。

3.2.1 abs/fabs函数（取绝对值）

　　该函数返回某个数的绝对值。所谓的绝对值，就是不看数据的正负号，只看剩下部分的内容。例如\(-3\)的绝对值是\(3\)，\(2.5\)的绝对值是\(2.5\)，\(0\)的绝对值是\(0\)。也就是说，正数和０的绝对值就是自己，而负数的绝对值是其相反数。

3.2.4 sqrt（开平方，获得平方根）

　　sqrt函数，是开平方的意思，其函数接口原型是double sqrt(double x);（也支持float和long double类型），返回类型为double类型（同上，支持其他２种类型），而且必然是正实数。负数不能开平方。例如int a=10; double x=sqrt(a);是个正确的函数调用。和其他函数一样，开平方函数并不会改变变量a的值。

3.2.5 pow（幂函数）

　　首先需要知道什么是“幂”：形如\(a^b=\overbrace{a\times a\times a...\times a}^{b个a}\)，而\(a^b\)就是一个幂，其中\(a\)是底数，\(b\)是指数。例如\(2^4=16,\quad3^2=9,\quad(-5)^0=1, \quad 2^{-2}=\frac{1}{4}\)。我们可以把\(a\)和\(b\)进一步拓展到实数范围。注意，底数\(a\)不能为０。

　　pow函数的接口原型是double pow(double x, double y)（同样支持其他两种实数类型），它需要两个参数，double a=1.8,b=4.1; double c=pow(a,b); double d=pow(-2.6, 9);是正确的函数调用。

　　应该意识到，sqrt是pow的一个特例，即指数为0.5时的情况。
