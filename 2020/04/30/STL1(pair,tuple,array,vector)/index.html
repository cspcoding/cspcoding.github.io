STL1(pair,tuple,array,vector)

发表于2020-04-30|更新于2025-05-01|基本知识STL
|阅读量:

　　本帖主要讲解STL标准模板库中的pair、array、string和vector，只需要学生学过数组和结构体就可以学习本帖。

一、pair

　　在 C++14 中，std::pair 是 STL（标准模板库）的一部分，定义于头文件 <utility> 中，不算是一种容器。它是一个轻量级的模板结构体，用于将两个不同类型的值组合成一个对象，常用于需要返回多个值或简化数据结构的场景。

　　pair不是一个必须掌握的STL。学生如果实在不会，可以使用结构体类型来平替，只不过代码写得稍多一点而已。对同学们的要求是“能读懂，写自愿”，即“必须要能读懂带有pair的代码；至于自己写代码时，可根据自己的实际能力来选择，只要写得又快又准就好”。

1.1 pair 的本质与定义

1.1.1 本质

  • pair 是 模板结构体，而非容器，但被归类为 STL 工具组件。
  • 包含两个公有成员变量：first 和 second，分别存储两个值。
  • 支持任意类型组合（如 int 和 string，甚至自定义类型）。

二、array容器

　　在 C++14 中，std::array 是标准库提供的固定大小的数组容器，定义于 <array> 头文件。它封装了传统 C 风格数组，提供了类型安全、接口标准化和与 STL 算法兼容的特性。在实际编码时，这个容器用得很少，因为绝大部分学生都更熟悉普通的数组写法（例如int a[10];）。所以对于array容器的学习要求是“能读懂，写自愿”，和pair一样。

2.2 核心特点

  1. 固定大小 std::array 的大小在编译时确定，无法运行时修改，但内存连续分配，性能接近原生数组。

  2. 类型安全 作为模板类，编译器会检查类型一致性，避免隐式类型转换错误。

  3. STL 兼容性 支持迭代器、范围 for 循环和 STL 算法（如 std::sort、std::find）。

  4. 聚合类型 可直接使用聚合初始化，无需显式调用构造函数。

2.3 优点

优点 说明
安全性 提供边界检查（at()），避免越界未定义行为
接口丰富 支持 front()、back()、fill() 等成员函数，操作直观
性能高效 内存连续，缓存友好；无动态内存分配开销
与 C 互操作 通过 data() 获取原生指针，兼容 C 风格 API
现代特性支持 支持 C++11 的初始化列表、C++14 的泛型 lambda 等

2.4 缺点

缺点 说明
固定大小 无法动态扩容或缩容，需预先确定大小
默认初始化风险 未显式初始化时，内置类型元素为未定义值（需手动初始化）
不支持动态分配 无法像 std::vector 通过 reserve() 预分配内存
多维数组限制 多维数组需嵌套定义（如 array<array<int, 3>, 2>），灵活性较低

2.5 适用场景

  1. 固定大小数据存储 如数学中的向量、矩阵，或需要频繁访问的配置参数。

  2. 与 C 接口交互 通过 data() 传递给需要原生数组的 C 函数。

  3. 替代原生数组 在需要类型安全和 STL 兼容性的场景下替代 T[N]。

  4. 性能敏感场景 内存连续且无动态分配开销，适合嵌入式或实时系统。

2.6 与原生数组的对比

特性 std::array 原生数组 T[N]
边界检查 at() 提供检查 无
大小获取 size() 返回大小 需手动计算或宏定义
赋值与比较 支持 operator= 和 operator== 需手动实现
类型安全 类型检查严格 可能隐式转换导致错误
内存管理 自动管理（栈分配） 需手动管理（可能堆分配）

2.8 总结

　　std::array 是 C++ 中处理固定大小数组的最佳实践，兼顾了安全性与性能。尽管无法动态调整大小，但其标准化接口和与 STL 的无缝集成使其在需要固定内存布局的场景中不可替代。对于需要动态扩展的场景，应选择 std::vector。

三、string容器

　　在 C++14 中，std::string 是标准模板库（STL）中专门用于处理字符序列的容器，属于 序列容器，定义于 <string> 头文件。它封装了动态字符数组的管理。

3.1 核心特性

3.1.1 序列容器属性

  • 顺序存储：字符按顺序存储在连续内存中，支持随机访问。
  • 动态扩展：自动管理内存，支持动态增减字符（如 push_back、resize）。
  • 固定字符类型：特化为 char 类型（std::basic_string<char> 的别名）。

3.1.2 与 C 风格字符串的对比

特性 std::string C 风格字符串（char*）
内存管理 自动分配/释放，避免泄漏 需手动管理（malloc/free）
安全性 边界检查（at()），防止越界 无保护，易引发缓冲区溢出
功能丰富性 提供 find、substr 等成员函数 依赖外部函数（如 strlen）
